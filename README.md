# Forma-MCP has moved

Forma-MCP now lives on Autodesk's own GitHub:

**https://git.autodesk.com/BIM360/forma-mcp-prototype**

This repository is only a signpost. Code, releases and issues are in the new place.

## What you need to do

- **Clone fresh.** The history was rewritten for the move, so an old clone cannot pull from the new repository. Keep your local `.env`, `personas.json` and token files, and copy them into the new clone.
- **Access.** Sign in at git.autodesk.com with your Autodesk account (VPN). If the link does not open for you, write to me on Slack.
- **Issues and ideas** go to the issues of the new repository.
